# 英语分班与四六级

### 分班

- 不参与分班考试的人群
  - 英语专业
  - 里尔学院
- 分班依据
  - 高考分数+英语分班考试成绩,两者占比并不明确,要我说高考成绩占 80% 以上
  - 分班考试是线上考试,90 分钟,简单的四级题目,多数人 45 分钟就能做完
- 分班比例
  - A:B:C=1:8:1
- 班级差距
  - 期中期末考试使用**同一套试卷**!!
  - 据说 A 班会压制高分,B 班 90 到 A 班变 85(存疑)
  - C 班周末要补课,A 班比 B 班多些内容(考试无关(应该吧?))
    :::tip
    建议去 B 班,不要去 C 班
    :::

### 四六级

- 不限制大一考四六级,与分班无关
- 因为本校考点容量有限,所以名额报完即止,有可能因此无法参与考试
- 最好不要缺考，虽然你只损失了钱，但是也占用了一个名额
- 四级听力会比高中听力难很多，需要多准备下，~~（江浙沪京爷可忽略）~~
- To 保研er：考六级的机会最多只有 4 次（大一下 ~ 大三上），大三下的六级成绩在保研前出不来；
- **考六级的黄金时期是大一下！！！**
- 不要幻想自己在大学里会学英语，大学英语课作用几乎为零，基本还是吃高中的老本，大三再去考真的力不从心（某小编血淋淋的教训/(ㄒoㄒ)/~~）。
- 六级和期末考试的时间冲突，而大一下大概率是最轻松的期末周，还是能够挤出时间备考的（大二和大三的考试会又多又难）。
