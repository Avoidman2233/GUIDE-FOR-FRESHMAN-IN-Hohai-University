# 序言

call back,容我回顾一下故事的起点
:::caution "要不是有钱赚,谁给你们办这些东西."
:::

最开始,我希望的有一个 pdf,甚至因为怯懦而不敢署名,冠以**盗版河海大学新生指南 2024**这样的名号,故事的起点便是如此.但感谢大家的支持,给出了如此的勇气,才有了今天的指北网站,有了资料的下载站.

当我去其他院校的类似网站采风,一种嫉妒与自卑常常在心里生发.但我相信着,哪怕是我毕业,这份对所谓美好未来的**希望**,这份对未曾谋面的同学的**爱意**,一定能够传下去.

**希望**.所谓的指北编辑部,总有一天,能够变成某种综合的团队.不止会有指北的网站,不止会有资源站,还会有小程序,会有自己的的社群,甚至会有自己的 app.

**爱意**.所有迷茫的,初来乍到的同学,都能够得到及时的充分的,不因为经济利益而驱动,真心的讲解与建议.

当那样的世界实现,或许我曾经为止皱眉的见闻与经历,哪怕是在最纯良的小东西身上,也不会再次重演,打破莫比乌斯之环.

我的任务并没有完成,我的工作也没有尽善尽美,但今日我可以如此回答:
:::tip 的确有傻子愿意倒贴钱
:::

:::details 主编的小小任性,诗兴大发,不建议观看
**就知道你们忍不住**

脚步抬起却迷惘,
心灵难止是惊慌,
谁也并非生而坚强,
今日却也撑起臂膀.

目光躲闪晦暗珍藏,
一丝愿相信的光芒,
那就抬脚,向着前方!

跌倒无数的,
思绪不甘的,
终给了奋起的力量,
并非启程就能担当.

再多些勇气又何妨,
那勇气本就在胸膛,
今日的夜道路不畅,
明日重见一个清晨.

终有一天是我能讲,
纵然永远为时尚早,
这份热忱永不散场，
自有来人接过行囊。
